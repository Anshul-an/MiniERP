# Contributing to MiniERP

Thank you for your interest in contributing!

## Development Setup

1. Clone the repo
2. Follow the setup instructions in README.md
3. Create a feature branch: `git checkout -b feature/your-feature`
4. Make your changes
5. Run tests: `npm test`
6. Commit using conventional commits: `feat:`, `fix:`, `chore:`, `docs:`, `refactor:`
7. Open a Pull Request

## Project Structure

See README.md for the full folder structure.

## Code Style

- Backend: TypeScript, NestJS patterns, Prisma for DB access
- Frontend: React functional components, custom hooks, Tailwind for styling
- Run `npm run lint` before committing

## Questions?

Open a GitHub Issue.

## Commit Style

Use conventional commits: feat/fix/chore/docs/refactor/style/test

## Testing

Run test stubs: 
pm test from backend directory.
